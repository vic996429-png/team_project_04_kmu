## 확인한 내용
- **처리 흐름:** 민원접수(비공개) → 부서지정(비공개) → 담당자 배정(비공개) → 최종답변(공개 전환)
- **실명제:** 로그인 또는 실명 확인이 필요하다.
- **처리기간:** 7일(주말·공휴일 제외)이며, 필요하면 연장될 수 있다.
- **공개 시점:** 처리 완료 전까지 비공개로 등록되고, 답변 후 공개 또는 비공개로 전환된다.
- **삭제/비공개 대상(요약)**
  - 구정과 무관하거나 정치적 목적이 있는 민원
  - 욕설·음란물 등 저속하거나 광고성인 민원
  - 근거 없는 비난
  - 특정인 실명 기재·비방
  - 동일인의 반복 게시
- **화면 표시 게시물 수:** 총게시물 10,058건(2026.11.5. 기준, 누적이며 기간 표시 없음)

## 서비스에서 쓰는 법
- **Q2:** 처리 기간 7일과 「그대로 제출해도 접수」 설명에 쓴다.
- **Q3:** 현행 게시판은 글이 올라온 뒤 삭제·비공개하는 사후 방식이라는 점을 설명할 때 쓴다. 필터 기준과 섞지 않는다.
- **주의**
  - 게시글 목록은 실제 민원이다. 제목·내용을 수집하거나 예시로 쓰지 않는다(지침 R4-5).
  - 10,058건은 연간 수치가 아니다.
