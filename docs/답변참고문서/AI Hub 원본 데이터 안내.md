## 4. 주의사항

1. **챗봇 답변용 폴더(RAG 입력)에 넣지 않는다.**
   - JSON 5개(약 330MB)는 창원시 콜센터·국민신문고 민원과 답변이다. 섞이면 성북구 질문에 창원시 답변이나 무관한 민원 답변을 가져올 위험이 크다.
   - CSV는 실제 욕설·혐오 문장이다. 「정치성향」을 유해로 분류하므로, 「구정 비판도 걸린다」는 틀린 답의 근거가 될 수 있다.
   - 그래서 `docs/답변참고문서` 대신 `docs/시험데이터`처럼 별도 폴더로 옮기기를 권한다.
2. **실제 민원 기반 데이터:** JSON은 공개 데이터이지만 실제 민원 원문에서 만든 것이다. 지침 R4-5(공개 데이터와 가상 민원만 사용)에는 「공개 데이터」로 들어간다. 다만 발표·시연 화면에 원문을 그대로 보이지 않고, 예시로 쓸 때는 [가상 예시]로 바꿔 쓴다.
3. **배포 저장소에 올리지 않는다:** 13주 GitHub·Vercel 배포 때 이 파일들을 저장소에 포함하지 않는다. AI Hub 데이터의 재배포·공개 가능 범위는 AI Hub 이용정책에서 [확인 필요]다. 용량도 GitHub 파일 한도를 넘는다.
4. **파일-데이터셋 대응 확인:** CSV 첫 줄(열 이름)과 JSON 첫 레코드를 열어 위 추정이 맞는지 확인한다 [확인 필요].
